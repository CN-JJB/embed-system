# AI Use Policy

AI is an accelerator, not a substitute for evidence, debugging, or understanding.

## Learning Modes

### AI-Free
Used for:

- baseline tests;
- critical Gates;
- first implementation of foundational mechanisms;
- selected debugging exams.

No direct solution generation.

### AI-Hint
AI may:

- ask diagnostic questions;
- point toward documentation;
- suggest what evidence to collect;
- offer incremental hints.

### AI-Assisted
AI may:

- review code;
- propose local refactors;
- generate test candidates;
- summarize known documentation after sources are identified.

The learner remains responsible for verification.

### AI-Native
Used in later large engineering work.

Agents may generate substantial code or research, but the learner/Leader owns:

- architecture;
- correctness;
- testing;
- debugging;
- performance claims;
- source traceability.

## Research AI Rules

Research/writing AIs must not:

- fabricate sources;
- fabricate experiments;
- claim code was run when it was not;
- cite AI output as evidence;
- silently resolve source conflicts by guessing.

Unknowns should remain explicit.
