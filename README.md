# embed-system

A long-term, evidence-driven learning system for becoming a strong Embedded Systems Engineer, with a focus on Embedded Linux, BSP, Linux drivers, SoC/platform engineering, bring-up, debugging, and performance.

> Status: bootstrap / Phase 0

The repository is maintained as a living tutorial, lab book, project portfolio, and career-alignment system. Editorial and research rules live under [`.editorial/`](.editorial/).
