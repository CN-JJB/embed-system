# M09 Gate Reference
A passing audit names shared state, owner/lifetime and exactly what each mutex protects. Queue invariant includes `0<=count<=capacity`, bounded indices, no push after close, and terminal `closed && count==0`. Push/pop hold the mutex for predicate checks and state changes; waits are `while` loops; close sets `closed` under lock and broadcasts. Worker is joined before condvars/mutex are destroyed. `volatile` is rejected as synchronization. TSan, when available, is supporting race evidence rather than a substitute for the contract. Regression covers repeated runs, close/wakeup, drain/consumer exit, join, and destroy.
