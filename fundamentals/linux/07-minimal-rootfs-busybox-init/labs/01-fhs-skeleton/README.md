# Lab 3.1 — Minimal FHS Root Filesystem Skeleton

## 1. Objective

Construct the minimal directory hierarchy conforming to the Filesystem Hierarchy Standard (FHS 3.0) required to boot an Embedded Linux system. Understand which directories hold stored target binaries and configuration, and which serve as mount points for kernel-backed pseudo-filesystems.

---

## 2. Theoretical Foundation

In Linux, the root filesystem (`/`) is the top-level namespace for all files, directories, device nodes, and virtual kernel interfaces. An Embedded Linux appliance requires only a minimal subset of the full desktop FHS:

| Directory | Type | Purpose | Persistence |
|---|---|---|---|
| `/bin` | Storage | Essential user command binaries (e.g. `sh`, `ls`, `cat`, `echo`, `busybox`) | Rootfs image |
| `/sbin` | Storage | Essential system administration binaries (e.g. `init`, `reboot`, `halt`, `mount`) | Rootfs image |
| `/usr/bin`, `/usr/sbin` | Storage | Secondary system utilities installed by applets | Rootfs image |
| `/etc` | Storage | System configuration files (`inittab`, `passwd`, `init.d/rcS`) | Rootfs image |
| `/dev` | Virtual / Node | Special device files representing hardware interfaces (`/dev/console`, `/dev/null`) | Populated by `devtmpfs` |
| `/proc` | Pseudo-FS | Process and kernel state information exported by `procfs` | Dynamically generated by kernel |
| `/sys` | Pseudo-FS | Unified device model, buses, drivers, and device tree exported by `sysfs` | Dynamically generated by kernel |
| `/tmp`, `/run` | Ephemeral | Temporary files and volatile runtime PID files | Volatile RAM (`tmpfs`) |
| `/mnt`, `/root` | Storage | Mount point for persistent media and root user home directory | Rootfs image |

> [!IMPORTANT]
> `/proc` and `/sys` contain NO files on disk. They must exist in the rootfs only as **empty directory mount points**. Attempting to put static files inside `/proc` before booting is a conceptual error; the kernel mounts its virtual filesystem over these directories at runtime.

## 3. Hands-On Execution

1. Create a rootfs staging workspace:
   ```bash
   mkdir -p rootfs-staging
   cd rootfs-staging
   ```

2. Create the minimal FHS directory skeleton:
   ```bash
   mkdir -p bin sbin usr/bin usr/sbin etc/init.d dev proc sys tmp run mnt root
   ```

3. Set directory permissions:
   ```bash
   chmod 755 bin sbin usr usr/bin usr/sbin etc etc/init.d dev proc sys mnt root
   chmod 1777 tmp run
   ```

4. Verify directory layout:
   ```bash
   find . -type d | sort
   ```
