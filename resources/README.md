# Resources — How to Navigate

If you are learning from the repository, use these files for different jobs:

| Need | Open |
|---|---|
| “What do I learn next?” | [`../START_HERE.md`](../START_HERE.md) |
| “I know the topic; exactly what should I read/source-read/do?” | [`TOPIC_RESOURCE_INDEX.md`](TOPIC_RESOURCE_INDEX.md) |
| “What are the trusted resource families and alternatives?” | [`CANONICAL_RESOURCES.md`](CANONICAL_RESOURCES.md) |
| “How does this topic fit the whole engineer skill tree?” | [`../roadmap/MASTER_LEARNING_MAP.md`](../roadmap/MASTER_LEARNING_MAP.md) |

`CANONICAL_RESOURCES.md` is deliberately a **library**, not a syllabus. Do not open a documentation homepage and try to read it linearly.

`TOPIC_RESOURCE_INDEX.md` is the actionable index. Search it by the unit ID from `START_HERE.md`, for example `P3.5`, `P4.4` or `P6.7`. Each unit names the relevant document/chapter/source target, an experiment and an exit criterion.

The normal learning loop is:

```text
START_HERE unit ID
→ matching TOPIC_RESOURCE_INDEX section
→ PRIMARY source slice
→ COURSE/MODEL explanation
→ SOURCE inspection where useful
→ learner-built experiment
→ evidence note
→ exit criterion
```
