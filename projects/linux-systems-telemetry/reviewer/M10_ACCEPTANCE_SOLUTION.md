# Reviewer Reference — M10 Acceptance
Expected architecture is FD -> validated parser/codec -> fixed record -> bounded by-value ring -> one worker -> stats -> status. Main owns path-opened FDs and borrows stdin. Worker inherits blocked SIGINT/SIGTERM; main alone unblocks after handler installation. Handler sets only the stop flag. Queue push/pop predicate checks and state mutation occur under the mutex in while loops; close is under lock and broadcasts; worker drains accepted records and exits on closed+empty; join precedes sync destruction. Codec is explicit 12-octet LE. Sum overflow is checked. Evidence labels must match actual execution.
