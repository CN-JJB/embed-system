# Reviewer Reference — M10 Operational Acceptance Evidence Mapping

This document provides the operational audit rubric for M10 Project Acceptance. Reviewers must evaluate learner submissions against the explicit evidence mapping below. "Program runs once" or "make test passes" does not constitute proof of correctness.

---

## Operational Evidence Mapping Table

| # | Requirement | Command / Path | What Counts as Evidence | What the Evidence Does NOT Prove | Pass / Fail Condition |
|---|---|---|---|---|---|
| **1** | Clean Strict Build | `make clean && make` | Zero compiler warnings, zero errors with `-std=c17 -O0 -g3 -Wall -Wextra -Wpedantic -Werror -pthread`. | Does not prove runtime correctness or absence of concurrency races. | **PASS**: Build exits 0 with zero diagnostic output.<br>**FAIL**: Any warning or compilation failure. |
| **2** | 12-Octet Codec & Signed Representation | `./build/test_unit` (`tests/test_unit.c:test_codec_golden`) | Hex dump / byte comparison matching wire specification: 8B timestamp LE, 1B sensor ID, 1B reserved, 2B wire value LE; `INT32_MIN` decoded via bit-preserving `memcpy`. | Does not prove caller correctly handles corrupted transport streams. | **PASS**: All codec tests pass including `INT32_MIN` regression.<br>**FAIL**: Any assertion failure or undefined signed cast behavior. |
| **3** | Parser Length & Range Validation | `./build/test_unit` (`tests/test_unit.c:test_parser_*`) | Deterministic return codes: `PARSER_BAD_FORMAT` for delimiter missing, `PARSER_RANGE_ERROR` for `sensor_id > 255`, `PARSER_TRUNCATED` for short input. | Does not prove non-blocking I/O or multi-threaded parser concurrency. | **PASS**: Parser unit tests verify all boundary rejection codes.<br>**FAIL**: Buffer overrun, crash, or silent data acceptance. |
| **4** | Resource Ownership (FD Ownership Table) | `src/main.c:main` & `scripts/fd_audit.sh` | Documented ownership table: `main` owns path FDs and closes on all paths; `main` borrows `STDIN_FILENO` and never closes it; `/proc/self/fd` shows constant FD count. | Does not prove absence of kernel descriptor exhaustion under high load. | **PASS**: Ownership table submitted and verified by code inspection and `fd_audit.sh`.<br>**FAIL**: Missing `close(fd)` or borrowed stdin closed. |
| **5** | Bounded Ring Queue Invariants | `src/queue.c` & `./build/test_unit` (`test_queue_*`) | Invariant `0 <= count <= CAPACITY` and `head/tail` arithmetic held under `q->lock`; value semantics (record copied by value). | Passing unit test does not prove freedom from data races under all OS schedules. | **PASS**: Structurally verified under mutex; unit test passes FIFO and full-wait checks.<br>**FAIL**: Pointer stored into ring or count updated outside mutex. |
| **6** | Push/Pop Predicate Loops | `src/queue.c:queue_push`, `queue_pop` | Both wait loops use `while` statements: `while (q->count == CAPACITY && !q->closed)` and `while (q->count == 0 && !q->closed)`. | Does not prove condition variables cannot experience spurious wakeups. | **PASS**: `while` loops verified; predicate rechecked under lock.<br>**FAIL**: Use of `if` statement for wait condition. |
| **7** | Clean Shutdown & Join-Before-Destroy | `src/main.c:main`, `src/queue.c:queue_close` | Trace/code proving: `queue_close` broadcasts; worker breaks loop on `closed && count == 0`; `pthread_join(worker)` finishes BEFORE `queue_destroy`. | Single run does not prove absence of shutdown races under heavy load. | **PASS**: Join explicitly precedes `queue_destroy` in source and execution trace.<br>**FAIL**: `queue_destroy` called before join or while worker runs. |
| **8** | Async-Signal Safety | `src/main.c:signal_handler`, `src/main.c:main` | Handler sets only `volatile sig_atomic_t g_stop_requested = 1`. Worker masks signals via `pthread_sigmask`. | Does not prove signals cannot interrupt slow system calls. | **PASS**: Handler conforms strictly to POSIX async-signal-safe list.<br>**FAIL**: Handler calls `printf`, `malloc`, `exit`, or mutex functions. |
| **9** | SIGTERM with Blocked / Open Input | `./scripts/integration.sh ./build/telemetry fixtures` | FIFO write side held open without writing; SIGTERM sent; service terminates promptly without waiting for input EOF. | Does not prove performance under rapid signal storms. | **PASS**: Pre-read stop check verified; integration test exits 0 on SIGTERM.<br>**FAIL**: Service hangs waiting for pipe data or EOF. |
| **10** | Normal EOF Termination & Coherent Stats | `./build/telemetry fixtures/valid.txt` | Output stats match input record count; count, sum, min, max reflect ingested records; process exits code 0. | Does not prove numeric overflow protection for infinite streams. | **PASS**: Output stats exactly match deterministic test data.<br>**FAIL**: Discrepancy between input records and final worker stats. |
| **11** | Address & Undefined Sanitizers | `make san` | Zero memory errors, zero leak reports from ASan, zero undefined behavior reports from UBSan across unit and integration suites. | ASan/UBSan do not detect multithreaded data races. | **PASS**: `make san` exits 0 with `detect_leaks=1`.<br>**FAIL**: Any memory leak, use-after-free, or UB report. |
| **12** | ThreadSanitizer Audit | `make tsan` | Separate build executed where runtime supports it. Honest environmental status reported (VERIFIED / PARTIALLY WORKING / UNAVAILABLE). | Silence from TSan does not mathematically prove race freedom across all schedules. | **PASS**: TSan executed or accurate limitation documented; zero races in reference code.<br>**FAIL**: Fabricated TSan report or combining ASan with TSan. |
| **13** | Unknown Fault Diagnostic Postmortem | `projects/linux-systems-telemetry/faults/unknown/` | Completed 8-step postmortem report; successful reproduction of hang using bounded fixture; regression proving close → wake → exit → join → destroy. | Diagnostic reasoning on one fault does not guarantee catching arbitrary production bugs. | **PASS**: All 8 steps documented with concrete evidence; regression test passes 100 cycles.<br>**FAIL**: Submitting code fix without hypotheses, evidence, or bounded reproduction. |
